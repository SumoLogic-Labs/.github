# Sumo Logic Labs

**Sumo Logic** delivers *Intelligent Operations for the AI era*: agentic AI-powered security and cloud log analytics that help teams **monitor, troubleshoot, automate, and defend**, all on one cloud-native platform.

- **DojoAI**: a multi-agent AI platform that triages, investigates, and resolves issues faster
- **Cloud SIEM**: automated alert triage and threat correlation built on log analytics
- **Logs for Security**: protection, compliance, and AI-guided search
- **Log Analytics**: monitor and troubleshoot cloud and on-prem systems before users notice

Learn more at [sumologic.com][sumo] · [Start a free trial][trial] · [Docs][docs]

## What lives here

This org hosts **community-supported, experimental open source projects** built by Sumo Logic engineers and the community: tools, integrations, and prototypes that make it easier to work with Sumo Logic.

| Project | What it does |
|---|---|
| [sumocli][sumocli] | Manage your Sumo Logic org from the command line (Go) |
| [sumobot][sumobot] | Slack bot for Sumo Logic |
| [sumologic-grafana-datasource][grafana] | Query Sumo Logic metrics from Grafana |
| [sumologic-prometheus-scraper][prom] | Send Prometheus-format metrics to Sumo Logic |
| [collector-management-client][cmc] | Manage installed Collectors in bulk (Python) |
| [sumo-report-generator][report] | Build Excel workbooks from Sumo Logic data |

Browse [all repositories][repos].

## Support

Projects here are provided **as-is** and supported by the community, not by Sumo Logic Support. To get help, open an issue in the project's repository. Contributions are welcome.
